FAQ

Frequently asked questions.

Is FinTrack a web app?

Yes. FinTrack is a web application designed to work across modern mobile, tablet and desktop browsers.

Is FinTrack available on Google Play?

Not currently. We do not have a Google Play Store developer account at this time, so there is no official Google Play listing yet.

Can I download the app?

The website includes an app download area for future official releases. Until an official package is published, the recommended option is to use the web app.

Where is my financial data stored?

The core standalone version can use browser-based local storage. Cloud backup and multi-device synchronization require a properly secured cloud backend.

Does FinTrack support money requests?

Yes. The product includes a Money Request feature for creating and tracking requests with people, amounts, messages, due dates and statuses.

Will there be cloud backup?

Cloud backup is planned as an extended capability. The website can present the feature now, while the production implementation should use a secure backend such as Firebase, Supabase or a custom API.
